# UI設計

## 1. 目的

この文書は、amazon-explorer のStreamlit画面で利用者が見る要素、操作手順、表示規則、エラー表現、アクセシビリティ上の現状を定義する。実装構造と状態管理は [FRONTEND.md](FRONTEND.md)を参照する。

## 2. 想定利用者と利用目的

利用者は、商品名だけでなく「静か」「白い」「1万円以内」「避けたい条件」のような要望を日本語の自然文で入力し、条件への近さを比較する。表示順位は推薦や購入保証ではなく、取得できた候補を現行スコア式で並べた参考情報である。

現行UIはローカル利用を主対象とする。ログイン、複数利用者向けの履歴管理、購入処理は提供しない。

## 3. 画面仕様

### 3.1 ページ設定

| 項目 | 現行値 |
|---|---|
| ブラウザページタイトル | `Amazon Product Search` |
| レイアウト | `wide` |
| 画面タイトル | `Amazon類似度検索` |

### 3.2 サイドバー

「設定」見出しの下に次を表示する。

| 表示 | 内容 |
|---|---|
| `Bonsai: ...` | `BONSAI_BASE_URL` の値 |
| `Amazon: ... / ...` | Outscraperのドメインと言語 |
| `取得件数: ...` | Outscraperへ要求する最大件数 |
| `Outscraper API key: existing/missing` | APIキーが空でないかだけを成功・警告表示 |
| `Bonsai Server: running/not running` | `/models` の疎通結果を成功・警告表示 |
| `表示件数` | 1から30のスライダー |

`SHOW_DEBUG_INFO=true` の場合だけ、商品名・属性・価格の総合係数と、必須語・優先語・関連語の重みをJSON表示する。現行のデバッグ表示には色語と特徴語の重みが含まれないため、全設定の確認手段としては使わない。

### 3.3 検索フォーム

- ラベル: `商品を検索`
- 入力形式: 高さ120pxの複数行テキスト
- 実行ボタン: `検索`
- 空白だけの入力: `検索条件を入力してください。` と警告し、検索しない

入力例:

```text
1万円以内で、白くて静かな日本語配列のワイヤレスキーボード。
テンキー付きは避けたい。
```

条件を具体化するときは、商品種別、価格帯、色、必要な特徴、避けたい特徴を一つの文章に含める。

## 4. 検索中と検索後の状態

### 4.1 検索中

検索開始後は次のスピナーを表示する。

```text
商品候補を取得してスコアリングしています。
```

検索は同期処理である。スピナーは段階別進捗、Outscraperのポーリング回数、完了予定時刻を表示しない。処理中にブラウザを閉じた場合の継続やキャンセルも保証しない。

### 4.2 0件

検索が正常終了しても表示対象がなければ、次を情報表示する。

```text
表示できる検索結果がありません。
```

0件はエラーとは限らない。Outscraperが正常に0件を返した場合や、正規化でタイトルなし・未対応通貨の商品が除外された場合にも発生する。

### 4.3 結果あり

区切り線の後に次の件数表示を行う。

```text
{取得結果数}件中 {実際の表示数}件を表示
```

`表示件数` は画面に描画する上限であり、検索済みの結果リストやOutscraperの取得件数を変更しない。スライダーを変更しただけでは再検索しない。

## 5. 商品カード

商品1件を枠付きコンテナに表示し、画像列と詳細列を1対3の比率で並べる。

| 要素 | 表示規則 |
|---|---|
| 順位・商品名 | `{順位}. {title}` を小見出しとして表示 |
| 商品画像 | `image_url` があれば列幅に合わせて表示。なければ「画像なし」 |
| 総合 | `total_score` を小数3桁で表示 |
| 商品名 | `title_similarity` を小数3桁で表示 |
| 属性 | `attribute_similarity` を小数3桁で表示 |
| 価格 | `price_score` を小数3桁で表示 |
| 進捗バー | `total_score` を0から1のバーで補助表示 |
| 実価格 | 整数を桁区切りした `{価格}円`。値がなければ「価格不明」 |
| 評価 | 小数1桁。件数があれば `{評価} / {件数}件`、なければ評価だけ。評価がなければ「評価なし」 |
| 商品リンク | `product_url` がある場合だけ「Amazonで開く」ボタン |
| 条件語 | 一致、不足、避けたい条件への一致を、それぞれ値がある場合だけ表示 |

条件語は ` / ` で連結する。「避けたい条件に一致」が表示された商品は、否定条件ペナルティを受けていても候補から自動除外されたとは限らない。

## 6. スコアの読み方

総合スコアは次の要素を組み合わせ、0から1へ制限した値である。

```text
0.45 × 商品名類似度
+ 0.35 × 属性類似度
+ 0.20 × 価格スコア
- 否定条件ペナルティ
```

- `商品名`: 入力条件と商品名のテキスト類似度
- `属性`: 商品説明等との類似度または重み付き条件一致率
- `価格`: 指定または推定価格帯への近さ
- `一致した条件`: 採点に使われた条件のうち見つかったもの
- `不足している条件`: 採点対象だが見つからなかったもの
- `避けたい条件に一致`: 商品テキスト中で見つかり、減点対象になったもの

スコアは取得データと設定に依存する。商品の品質、安全性、在庫、価格の最新性を保証しない。詳細な計算規則は [DESIGN.md](DESIGN.md) と [BACKEND.md](BACKEND.md)を参照する。

## 7. メッセージとエラー表示

| 状況 | 種別 | 利用者向け表示 | 次の行動 |
|---|---|---|---|
| 入力が空 | warning | `検索条件を入力してください。` | 商品条件を入力して再送信 |
| APIキーなし | sidebar warning | `Outscraper API key: missing` | `.env` を設定してアプリを再起動 |
| Bonsai疎通不可 | sidebar warning | `Bonsai Server: not running` | Bonsaiサーバーと接続先を確認 |
| 検索処理の例外 | error | `検索に失敗しました。設定と外部サービスの状態を確認してください。` | 起動ターミナルのログを確認 |
| 正常な0件 | info | `表示できる検索結果がありません。` | 条件を広げて再検索 |
| 商品画像なし | info | `画像なし` | 商品名やリンクで判断 |

検索例外の詳細は画面に表示しない。APIキー、外部レスポンス、スタックトレースの漏えいを避けるためである。診断方法は [TROUBLESHOOTING.md](TROUBLESHOOTING.md)を参照する。

## 8. 操作フロー

1. サイドバーで Bonsai が `running`、Outscraper API key が `existing` であることを確認する
2. 商品条件を自然文で入力する
3. 「検索」を押す
4. スピナーが消えるまで待つ
5. 総合スコアだけでなく、一致・不足・否定条件と価格を比較する
6. 必要なら表示件数を変える
7. 商品ページを確認するときだけ「Amazonで開く」を押す

商品ページの価格や在庫を最終判断の正とする。外部リンク先の内容と安全性は本アプリが保証しない。

## 9. アクセシビリティ

### 9.1 現在利用できる手掛かり

- スコアはバーだけでなく数値とラベルでも表示する
- 状態は色だけでなく `existing/missing`、`running/not running` の文字でも示す
- 価格不明、評価なし、画像なしを文字で明示する
- 検索入力にラベル、実行操作にテキスト付きボタンを使う
- 商品リンクは用途が分かる「Amazonで開く」という文言を使う

### 9.2 未確認・未実装

- 商品画像へ商品名に基づく明示的な代替テキストを設定していない
- フォーカス順、キーボードだけでの操作、スクリーンリーダー読み上げを試験していない
- エラー発生時のフォーカス移動やライブリージョンを独自実装していない
- 小画面、拡大表示、高コントラスト、色覚多様性の受入試験がない
- 日本語と英語が混在するステータス文言がある

公開範囲を広げる前に、Streamlitの生成HTMLを実際のブラウザと支援技術で確認する。未確認事項は [TECH-DEBT-TRACKER.md](TECH-DEBT-TRACKER.md) で追跡する。

## 10. UI受入確認

外部APIを呼ばない起動確認:

```sh
uv run streamlit run app.py --server.headless true
```

手動確認項目:

- ページタイトル、画面タイトル、サイドバーが表示される
- 空入力で警告が出て検索が始まらない
- 表示件数を1から30で変更できる
- APIキーの実値が画面に出ない
- Bonsai停止時も画面自体は起動し、警告表示になる
- 検索例外の詳細が画面に出ず、サーバーログには診断情報が残る
- 成功時に件数、各スコア、価格、評価、条件語、存在するリンクが表示される
- 表示件数変更だけでは検索が再実行されない

実検索を伴う確認ではOutscraperの利用料金と取得件数を事前に確認する。
